# NNNN. タイトル

- 状態: 提案 | 採用 | 却下 | 置き換えられた (→ NNNN)
- 日付: YYYY-MM-DD
- 関連: Issue / PR / 他の ADR へのリンク

## 状況

何が問題で、どんな制約があるか。決定を迫った事実だけを書く。

## 決定

何を、どう決めたか。「〜する」と言い切る。

## 帰結

この決定で得られるもの、失うもの、新しく生じる制約やリスク。良い面だけでなく悪い面も書く。

## 代替案

検討して **却下した** 案と、却下した理由。

## spike の結果 (spike の ADR だけ。通常の ADR では節ごと削除する)

### 再現手順

### fixtures の場所

採取したデータ (golden fixtures など) のパスと、どう作ったか。

### go / no-go

判定 (go / no-go / 条件付き go) と、その根拠になった実測。

no-go または条件付きの場合に、どうするか。代替の案と、その影響範囲。
